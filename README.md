#  Biblioteca Digital UniFECAF

Projeto desenvolvido como parte dos requisitos acadêmicos da disciplina de **Design Web** no curso de **Análise e Desenvolvimento de Sistemas** da UniFECAF.

##  Sobre o Projeto
A plataforma da **Biblioteca Digital UniFECAF** foi construída para modernizar e facilitar o acesso dos estudantes a livros, materiais acadêmicos, conteúdos de apoio e informações institucionais, contando com uma interface intuitiva, moderna e totalmente responsiva.

##  Links de Acesso
- **Site Online (Netlify):** [Aceder ao Projeto Online](https://animated-dodol-dfa165.netlify.app)

##  Tecnologias Utilizadas
- **HTML5 Semântico:** Estruturação correta das páginas e seções.
- **CSS3 / Flexbox & Grid Layout:** Estilização visual alinhada à identidade institucional da UniFECAF (Paleta Azul/Verde e fontes *Inter*) e adaptabilidade via *Media Queries*.
- **Controlo de Versão:** Git e GitHub.
